Link CSV Google Sheets
Cara mendapatkan link ini:
  1. Upload / copy-paste file report WMS asli (Stock Warehouse By Location) ke Google Sheets — tidak perlu diedit atau diubah formatnya.
  2. File → Share → Publish to web.
  3. Pilih sheet yang benar, format Comma-separated values (.csv), klik Publish.
  4. Salin link yang muncul, tempel di kolom atas.
Aplikasi otomatis mendeteksi baris header dan kolom yang dibutuhkan (Item No, Item Description, Storage Location Id, Base UOM, Stock On Hand Qty), serta menjumlahkan qty antar lot secara otomatis.
