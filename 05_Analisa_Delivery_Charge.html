Catatan: "Delivery Charge" diambil dari file Other Transaction Report pada kolom Description (mencocokkan teks "Delivery Charge", tidak peka huruf besar/kecil) dan dijumlahkan per Receipt No dari kolom Amount — jika satu Receipt No memiliki beberapa baris Delivery Charge, semuanya dijumlahkan. Penghubung antar kedua file adalah kolom Receipt No. Jika satu Receipt No memiliki beberapa NP No (multi item), maka NP No digabung dipisahkan koma dan kolom lain (Order Date, Salesperson, Status, Customer, Phone) mengikuti baris pertama dari Receipt No tersebut. Jika Status berbeda-beda dalam satu Receipt No, akan ditampilkan sebagai "Campuran".

Secara default, KPI/grafik/tabel detail & tabel per hari hanya menampilkan data bulan berjalan (bulan ini) — gunakan panel Filter Periode di atas untuk mengubahnya. Tabel Growth Delivery Charge per Bulan menampilkan bulan Januari s/d bulan berjalan (bulan setelahnya tidak ditampilkan). Bulan-bulan penuh (sebelum bulan berjalan) menggunakan summary sebulan penuh untuk LY maupun TY. Bulan berjalan dipotong di tanggal hari ini untuk keduanya (LY dan TY), sehingga perbandingan adil (misal LY Juni 1–25 vs TY Juni 1–25). Kolom LY diambil dari file Other Transaction Report Tahun Lalu; % Growth dihitung sebagai Selisih ÷ TY.
